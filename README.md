# Vehicle Rental System

A Java-based Vehicle Rental Management System developed using Object-Oriented Programming (OOP), Data Structures & Algorithms (DSA), Exception Handling, and JDBC with MySQL integration.

## Features

* Vehicle Management
* Customer Registration
* Vehicle Rental and Return
* Rental History Tracking
* Revenue Analysis
* MySQL Database Integration
* Exception Handling
* Vehicle Availability Tracking
* Maintenance Scheduling
* Electric Vehicle Support
* DSA Implementations

  * Stack
  * Min Heap
  * Binary Search
  * Quick Sort
  * Graph (BFS)

## Technologies Used

* Java
* JDBC
* MySQL
* Object-Oriented Programming
* Data Structures and Algorithms

## How to Run

1. Install Java JDK 17 or later.
2. Install MySQL Server.
3. Create database:

CREATE DATABASE vehicle_rental_db;

4. Update database credentials inside DatabaseManager.
5. Add MySQL JDBC Connector JAR.
6. Compile and run:

javac VehicleRentalSystem.java
java VehicleRentalSystem
